# Final Project

<br>

해당 프로그램은 키오스크 이용이 어려운 사용자들을 위한 사용 도우미 입니다.
<br><br>
본래 목적은
<br><br> 
사용자의 요청 ->  화면에서 키오스크 화면을 인식하여 YOLO를 통해 버튼 UI를 인식 -> ocr로 글자를 인식하여 llm으로 전달 -> Gemma가 어떤 버튼을 눌러야 하는지 알려줌 -> 해당 ui에 표시와 함께 한글로 표시

현재 한계로는 메모리가 부족하여 LLM으로 넘어가는 도중 시스템이 강제로 종료되게 됩니다.
<br>
또한 가중치 학습파일이 없어 UI를 인식하기가 어렵습니다.

- main.py -> 실행파일
- llm_handler.py -> gemma에게 요청을 보내는 파일
- ocr_det.py -> ocr로 글자를 인식하는 파일
- yolo.py -> yolo 사용 파일
